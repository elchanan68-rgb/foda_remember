# סבתא פודה — משפחת סמינה

אלבום זיכרונות משפחתי בעברית, עם קורות חיים, סיפורים וגלריית תמונות. האתר מותאם למסכים קטנים וגדולים. התמונות נשמרות ב־Supabase Storage פרטי ומוגשות בקישורים חתומים זמניים.

## התקנה ופריסה

הפרויקט משתמש ב־GitHub Pages לאתר וב־Supabase Edge Function למסד הנתונים ולהעלאות. יש לעבוד בענף נפרד, להריץ את הבדיקות, ואז למזג ל־`main`:

```sh
npm ci
npm test
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase migration list
npx supabase db push
npx supabase functions deploy family-memories
```

ב־Supabase → Edge Functions → Secrets נדרשים:

- `TURNSTILE_SECRET_KEY` — סוד Cloudflare Turnstile.
- `ALLOWED_ORIGINS` — origin מדויק, ללא נתיב. עבור האתר: `https://elchanan68-rgb.github.io`.
- `FAMILY_AUTO_APPROVE_CODE` — קוד משפחתי; נדרש לפרסום אוטומטי ולכל העלאת תמונות.
- `FAMILY_DELETE_CODE` — קוד מנהל נפרד לאישור/דחייה, מחיקה וניהול תמונות.

אין להכניס ערכים אלה ל־Git, לקובצי האתר או להודעה. Supabase מספקת לפונקציה את מפתח השרת דרך סביבת הריצה. `public-config.js` מכיל רק כתובת API ומפתח Turnstile ציבורי.

יש להחיל את כל המיגרציות לפני פריסת הפונקציה. `supabase/functions/.env.example` הוא דוגמה בלבד; לפיתוח מקומי מעתיקים אותו ל־`.env` מקומי שלא מעלים ל־Git.

## יכולות

- שליחת טקסט, תמונה בלבד, או סיפור עם תמונות. לכל זיכרון עד 10 תמונות; תמונות JPG, PNG ו־WebP נבדקות גם לפי תוכנן. דפדפנים תומכים יכולים להמיר HEIC לפני השליחה.
- קוד משפחתי נדרש לתמונות. סיפור ללא קוד ממתין לאישור. מנהל יכול להיכנס דרך כפתור „ניהול”, לאשר או לדחות פריטים ממתינים, למחוק זיכרונות, למחוק תמונה בודדת ולבחור תמונת שער.
- קורות חיים עם תקציר, מקום לידה, ילדות, הורים, עלייה וסיפור מלא. העריכה דורשת `FAMILY_AUTO_APPROVE_CODE`; נשמר עותק קודם בכל עריכה.
- תמונות ממוזערות לטעינה מהירה, תמונת תצוגה/אייקון לקישורים, ותצוגת טעינה/שגיאה.
- מנגנון אחסון עוצר העלאות תמונות ב־800MB (80% מתקרת 1GB שהוגדרה לפרויקט), מציג התראה ומאפשר להמשיך לשלוח טקסט. זו תקרה פנימית בלבד; יש לבדוק גם את עמוד Usage של Supabase.
- הגבלת שליחות, הגבלת ניסיונות קוד, אימות Turnstile, בדיקת מקור (CORS), בדיקת סוג וגודל קובץ, ומגבלות קלט בצד השרת.

## בדיקות

```sh
npm test
```

בדיקות Playwright כוללות זרימת סיפור, שמירה מקומית, תמונת שער, רספונסיביות ברוחבי 360, 390, 768 ו־1280 פיקסלים, סריקת נגישות אוטומטית, ובחירת 11 תמונות. בדיקות אלה אינן מחליפות בדיקה מול Supabase אמיתי, iPhone אמיתי או HEIC ממכשיר אמיתי. יש לבצע בדיקת העלאה, עריכת קורות חיים, אישור/דחייה ומחיקה באתר החי אחרי הפריסה.

## פרטיות ומגבלות

- אין חשבון משתמשים: קוד משפחתי מאפשר פרסום מיידי, וקוד מנהל פותח פעולות ניהול. יש לשתף אותם רק עם בני משפחה מורשים. הגבלת ניסיונות מאטה ניחוש קודים אך אינה זהות משתמש.
- בלי חיבור תקין ל־Supabase, זיכרונות מקומיים נשמרים בדפדפן הנוכחי בלבד ואינם משותפים.
- תמונות מאוחסנות ב־bucket פרטי ומוצגות בקישורים חתומים שפגים לאחר 24 שעות; האתר מרענן אותם כשהוא נטען מחדש.
- הקצאת מכסת האחסון תלויה במדיניות Supabase ובשימוש הכולל בפרויקט. הסף באתר אינו מבטיח שהחשבון כולו יישאר במסגרת החינמית.
